## 一、已确认的核心设计决策

1. **替换范围**：以新效果图（`能力升级.png`、`工具进阶.png`）为主完整替换随身商店弹窗 `PersonalShopFrame` 及右上角金币胶囊。
2. **图标与进度条**：工具进阶卡彻底移除 3D `ViewportFrame`，改用 2D 道具图标；全部 5 张升级卡移除旧版圆点/阶数进度条（`ProgressFrame`）。
3. **文案与对比框**：
   - **能力升级卡**：对比框精简为单行变化（`当前 → 下阶`，移速满级标注无限冲刺，画符显示人数，出售显示百分比）。
   - **工具进阶卡**：卡片顶部直接显示当前装备名，右上角挂黄色 `已装备` 标签；对比框为两行——白字黑描边显示当前属性，金黄字（`#fdd705`）黑描边显示下阶装备名与属性。
   - **多语言**：保持 `Scripts/ReplicatedStorage/Scripts/Shared/GameTexts.luau` 英文源词条，中文化通过本地化表更新流程完成。
4. **金币栏衔接**：新金币胶囊（`frame_money` + `icon_money_m`）作为常驻组件放在右上角，移除原右上 `StatusFrame` 中的旧 `CoinsText`，且在打开商店弹窗时保持位于模态遮罩之上。
5. **切图上云管线**：通过批量上传（Studio MCP `upload_image` / Open Cloud）生成 `Assets/UI/evil_shop_assets.json` 清单，由 Edit 构建脚本读取清单幂等重建模板并导出 `.rbxm`。

## 三、UI 模板层级与布局设计（1920×1080 基准画布）

### 1. 常驻金币胶囊与主 HUD 调整（`ReplicatedStorage.UI.GameScreenGui`）

为保证金币胶囊**平时常驻右上角**且**打开商店弹窗时不被 `ModalButton` 遮暗**，同时全项目仅保留唯一一个 `CoinsText`：

- **新增顶层画布 `OverlayCanvas`（`Frame`，`1920×1080`，居中锚定，挂载 `UIScale`，`ZIndex = 900`）**：
  - 置于 `GameScreenGui` 下与 `CenterFrame`、`WindowCanvas` 平级；
  - 由 `UIManager/init.luau` 的 `Resize()` 同步更新视口等比缩放。
- **`OverlayCanvas.CoinsFrame`（`ImageLabel`，贴图 `frame_money.png`）**：
  - 位于右上角（参考效果图 `Position = (1682, 28)`，`Size = (210, 65)`）。
  - 子节点 `MoneyIcon`（`ImageLabel`，贴图 `icon_money_m.png`，`Position = (-42, -14)`，`Size = (107, 89)`）。
  - 子节点 `CoinsText`（`TextLabel`，`DesignTextSize = 32`，纯数字显示，白字 + 黑色 `UIStroke` `ScaledSize` `Thickness = 0.06` + 阴影层）。
- **现有 `CenterFrame.StatusFrame` 调整**（`Tools/Gameplay/build-game-assets.luau`）：
  - 移除 `StatusFrame.CoinsText`，避免与右上角金币胶囊重复；
  - 将 `StatusFrame` 整体下移至 `y = 112`（紧贴金币胶囊下方），高度由 `240` 收缩为 `184`（仅保留 `TitleText`、`CarryText`、`StockText`）；
  - `GameScreenGuiManager.luau` 初始化收集 `self.labels` 时同时扫描 `OverlayCanvas` 下的 `TextLabel`，使 `ClientProcessingManager` 的 `self:Text("CoinsText", ...)` 无缝衔接。
