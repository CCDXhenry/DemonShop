## 2026-11-17 连续颜料改为客户端主导

- 用户反馈白膜颜料不连续。源码定位到三处原因：显示与 0.08 秒上报绑定；确认删除本地预览后换成服务端笔划；同面采样距离超过 3 倍覆盖半径时主动断线。
- 本地显示改为逐帧独立补采样，间距 3 屏幕像素、单帧最多 256 点；同一手势跨帧追加，短直线共线合并。覆盖率请求继续独立限频采样，不混用历史姿态计算权威覆盖。
- 操作者会话的本地颜料保留至身体移除，不被 PaintPose 或补发历史替换；抬笔、离开可涂表面、跨部位和跨面有明确断笔边界，不跨空气连线。
- 单身体本地最多 8192 个合并后线段；服务端 2048 点笔划历史预算独立保留。使用现有模板和回收池，无新增运行时 UI 结构。
- 27 个业务文件 strict 通过；离线共 77 条断言（38 规则、13 权威画符、7 复制、9 连续几何、10 生产视图）。视图测试使用真实 Lune GUI 实例，验证跨帧延长、确认不删除、重复确认、断笔隔离及回收。
- Script Sync 已核对新几何模块、逐帧采样和删除旧确认擦除路径；按此前同意的重启测试方式加载新会话，正常步行、击晕和搬运上桌。
- 原生鼠标先画横跨手臂—躯干—另一侧手臂的长线，再画头部至腿部的长线，视口可见连续线条，进度达到 11%。只读统计 8 个 SurfaceGui、12 个合并线段，等待 0.35 秒后 12 个均保留。工具中未读到 错误日志；未执行高延迟及双人专项验收。

## 2026-11-17 灵敏度调校

### 第二次反馈：更快且以客户端表现为主

- 用户再次要求提速并优先客户端表现。灵敏度 0.007 → 0.018、展示角速度 3.6 → 10 rad/s、输入响应 16 → 30；保留死区、俯仰限制与松手停止。
- 移除客户端相对上次上报角度的 ±0.3 rad 限制；PaintPose 确认只处理笔迹与进度，不再回写操作者角度。观察者仍平滑跟随；跨 ±π 时按最短角度插值。
- 服务端按客户端提供的有界姿态检查采样，不再以数据包到达间隔限制展示角速度；无有效采样不增加覆盖率，也不回退展示姿态。会话归属、递增序号、请求频率、有限数、可见表面和面积去重仍由服务端校验。
- 26 个业务文件 strict 通过；38 条规则、13 条画符、7 条复制断言通过（共 58 条）。新增覆盖快速旋转、仅姿态批次不加进度、角度归一与旧包不可回退。
- 改动已同步至 Edit 缓冲区。用户在当前绘制进度 61% 时明确选择“现在重启，直接体验更快的新版”，因此重启获授权的测试会话加载改动。
- 重启后客户端与服务端均读到 0.018 / 10 / 30。正常输入重新搬运上桌；原生鼠标拖画经确认保留连续笔迹，进度达到 3%，松手后 0.25 秒旋转漂移为 0。窗口一度处于超出屏幕的非最大化尺寸，重新最大化后校正了输入坐标。未做模拟高延迟或双人专项测试，不把本次局部输入观察扩大为完整网络验收。

### 第一次反馈：偏慢，需要更灵敏

- 用户实测反馈“偏慢，需要更灵敏”。将 PaintSensitivity 从 0.004 提高至 0.007（+75%），PaintAngularSpeed 从 2.4 提高至 3.6 rad/s（+50%）。死区 1.5 像素、阻尼 16、俯仰限制与松手停止保持原设定。角速度参数由客户端与服务端共用，避免本地加快却被服务端按旧限速拒绝。
- 配置 strict 通过，38 条规则、10 条画符、7 条复制断言通过。
- Script Sync 的 Edit 编辑缓冲区已读到新参数；调校前的运行会话仍缓存旧参数，需重启后才生效。
- 当前只读状态显示金币 200、桌/池/祭坛/架均为空、玩家未处于绘制。UI 隐藏的 ProgressText 留有 99% 文本，因此不能凭该残留文本判断尚有 99% 材料；也不能凭金币状态追认未被观察的完整玩家流程。
- 已重启获授权的测试会话，客户端与服务端实际 require 均读到 0.007 / 3.6 / 阻尼 16 / 死区 1.5；金币仍为 200。重新通过正常移动、三击、肩扛、门洞和楼梯到达工作台；原生鼠标拖画产生连续笔迹并从 0% 达到 3%。此为新参数加载与局部输入验证，灵敏度是否合适仍属用户主观体验，完整加工验收状态不因此改变。
