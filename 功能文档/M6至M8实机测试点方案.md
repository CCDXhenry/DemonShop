# 《恶魔商店 (DemonShop)》M6 ~ M8 实机测试点方案

> **对应需求基线**：[docs差异评估与阶段实现方案.md](./docs差异评估与阶段实现方案.md)（第二阶段 M6 ~ M8）  
> **适用场景**：Studio Play / Local Server / 真机与设备仿真手工实机验收（含 PC 单人、PC 双人联机、移动端横/竖屏）  
> **测试原则**：按 **P0 核心闭环 → P1 高风险边界与异常恢复 → 跨阶段联动 → 多人隔离与同步 → 移动端适配 → 观感/手感/性能** 分层执行，确保功能正确且实机表现达标。

## 0. 测试前置准备与提速指引

### 0.1 环境检查（开测前确认）
- [ ] Studio 打开目标场景：`Place1`（PlaceId `110812537538556`），确认 Script Sync 已同步最新脚本，无未保存的脏改动。
- [ ] 打开 Studio `Output` 窗口并清空，全程观察是否存在服务端/客户端红色报错（`Error`）或高频 `Warning` 刷屏。
- [ ] 确认本局经济开关 `SessionOnlyEconomy = true`：每次新开 Play 进服金币应为 `0`，5 项个人升级初始均为 `Lv.1`（武器 `W01`、搬运 `T0`、移速 `Lv.1`、画符 `1 人`、出售 `+0%`）。

### 0.3 推荐实机执行顺序
1. **第一轮（PC 单人 Play）**：先通跑 M8 街道刷怪 + `W01~W06`、M7 `T0~T4` 搬运与入池、M6 1~5 人连画的 **P0 主闭环**。
2. **第二轮（PC 单人 Play）**：集中验证 **P1 高风险边界/异常恢复** 与 **跨阶段联动（M1~M5 × M6~M8）**。
3. **第三轮（Studio Local Server 2 Players）**：验证 **双人个人隔离、接手续画、旁观同步与互斥抢占**。
4. **第四轮（Studio Device Emulator 移动横屏 + 竖屏）**：验证 **5 人画符取景、触控操作区切换与随身商店**。
5. **收尾检查**：填写第 7 节《观感、手感与性能专项验收表》与第 8 节《缺陷记录表》。
