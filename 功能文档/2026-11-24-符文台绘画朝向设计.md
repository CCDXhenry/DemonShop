# 符文台绘画朝向设计

日期：2026-11-24

## 问题

`RuneBodyTable` 的 `TransferStartAnchor` 在工作台正前方，和 RUNE TABLE 牌子同一侧。这个站位是对的，不移动。

当前绘画有两处反了：

- 俯视镜头把牌子这一侧放到画面上方，相当于从砖墙对面看下来。
- 白膜头朝世界 -X（西），压在台面腿线上。台面发光轮廓的圆圈在东边，双腿在西边。

## 朝向契约

牌子、`TransferStartAnchor`、`BodyPlacementAnchor` 和台面轮廓保持原位。只改 `PaintRotation` 的两个函数。客户端镜头和服务端落笔都读它们。

躺平后：

- 头朝世界 +X，落在东边的圆圈上，画面左侧。
- 脚朝世界 -X，落在西边的腿线上，画面右侧。
- 胸口朝世界 +Y。

镜头仍在摆放锚点正上方 `PaintCameraHeight`（10.5 studs）。画面上方朝世界 +Z（台子远处、砖墙一侧），画面下方朝牌子。

```lua
function Rotation.TablePose(position: Vector3): CFrame
	-- 头朝东（台面圆圈、画面左侧），脚朝西（腿线），胸口朝上。
	return CFrame.fromMatrix(position, -Vector3.zAxis, Vector3.xAxis)
end

function Rotation.CameraPose(position: Vector3): CFrame
	-- 正上方。画面右侧朝世界 -X，画面上方朝世界 +Z。
	local eye = position + Vector3.yAxis * Config.PaintCameraHeight
	return CFrame.fromMatrix(eye, -Vector3.xAxis, Vector3.zAxis)
end
```

两个函数一起绕竖直轴转 180°。画面上仍是头在左、脚在右。台子局部轴相对镜头的关系不变，拖拽方向和自动翻面的手感保持原样。翻面仍绕头脚那根轴转半圈。

`Scene.AutoRunePose` 调用同一个 `TablePose`。自动符文台没有头脚轮廓，白膜头也朝东。

不新增网络字段。不改锚点、台面、牌子。镜头高度、视野和进出过渡不变。笔刷半径、覆盖率和进度阈值不变。祭坛堆叠的 `PaintLiePitch` 不改。历史扫描脚本不改。
